| 术语 | 含义 | 投资相关性 |
|---|---|---|
| TCV / 总合同价值 | 当期签订的合同在整个合同期内的潜在总额,假设期权全部行权、合同不被终止 | 反映签约势头;含未行权期权,季度波动大,不能当当年收入 |
| ACV / 年合同价值 | 当期签约总额除以这些合同按金额加权的平均年限 | 比 TCV 更接近每年能确认的收入规模 |
| RDV / 剩余交易价值 | 期末全部合同尚未履行的剩余总额,同样假设期权行权、合同不终止 | 在手合同的上限口径;约为 RPO 的 2.7 倍,含可被政府提前终止的部分 |
| RPO / 剩余履约义务 | 已签合同中不可撤销、尚未确认为收入的金额(会计口径),不含一年以内的合同 | 未来收入可见度的保守口径,以商业合同为主 |
| NDR / 净收入留存率 | 一年前的客户在最近 12 个月的支出,除以这些客户前一个 12 个月的支出 | 高于 100% 说明老客户在加单;2Q26 为 157%,是收入加速的主要来源 |
| 客户数 | 过去 12 个月确认过收入的组织,大型政府机构的不同分支分别计数 | 看获客入口;政府分支拆开计数,与普通 SaaS 的客户数不可直接比 |
| IDIQ / 不定期不定量合同 | 政府先定合同上限和期限,之后按任务单逐笔下单付款的合同形式 | 上限不等于收入;FY2025 末约 123 亿美元未拨款上限未计入 RDV |
| BPA / 一揽子采购协议 | 政府与供应商预先谈好价格和条款,下属单位按需直接下单的协议 | 降低后续采购门槛,但协议金额只是上限 |
| 合同上限 / Ceiling | 合同允许政府下单的最高金额,不承诺一定花完 | 新闻里的百亿美元合同多指上限,不能当成收入 |
| 已拨付 / Obligated | 政府已正式划拨、承诺支付的合同金额 | 比上限更接近未来收入;陆军企业协议截至 2026-03 已拨付占上限 3.8% |
| 任务单 / Task Order | 在 IDIQ 或企业协议框架下,具体单位针对具体需求下的订单 | 任务单拨款的节奏决定上限转成收入的速度 |
| 企业协议 / Enterprise Agreement / EA | 把一个机构分散的多份合同合并成一份长期总协议,统一价格和条款 | 陆军企业协议合并 75 份合同,主要影响采购效率,不等于新增需求 |
| 便利终止 | 政府可以不说明理由、在合同期内提前终止合同的条款 | 政府合同因此多不计入 RPO,在手合同的确定性低于商业合同 |
| 正式项目 / Program of Record | 列入国防部常规预算、有长期经费安排的采购项目 | Maven 2026-03 转为正式项目,经费从临时拨款转为年度预算 |
| USAspending | 美国联邦政府公开合同与拨款数据的官方网站 | 可追踪各机构对 Palantir 的年度拨付;不含涉密合同,分包记在总包商名下 |
| CDAO / 国防部首席数字与人工智能办公室 | 美国国防部负责数据与人工智能采购和推广的机构 | Maven 智能系统合同的发包方 |
| Maven / Maven 智能系统 | 用 AI 处理卫星、雷达、无人机等战场数据,识别目标并支持指挥决策的国防部系统 | 国防业务中增长最快的项目,上限已从 4.8 亿升至约 12.75 亿美元 |
| TITAN / 战术情报目标接入节点 | 美国陆军的机动地面站车辆项目,为远程精确打击提供实时情报 | 软件公司首次作为硬件项目主承包商;2026-09 进入首批生产 |
| Army Vantage | 美国陆军的全军数据平台,由 Palantir 软件支撑 | 陆军合作的起点,2019 年生产协议上限 4.58 亿美元 |
| 训练营 / Bootcamp | 客户带真实数据参加,1–5 天内做出可用流程的获客方式 | 缩短试点周期,是美国商业客户数加速的入口 |
| 单一来源 | 不经竞标、直接授予某一供应商的采购方式 | 反映替换难度,也是国会与媒体争议的焦点 |
| NHS / 英国国家医疗服务体系 | 英国公立医疗系统,NHS England 是其在英格兰的管理机构 | 联邦数据平台合同(上限 3.30 亿英镑)是国际政府业务的标志性合同 |
| AIP / 人工智能平台 | Palantir 2023 年推出的产品,让大模型在权限内读取客户业务数据、起草方案,人工审批后执行 | 2023 年以来美国商业客户与老客户加单加速的主要来源 |
