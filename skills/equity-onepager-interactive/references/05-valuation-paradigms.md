## 0. 统一模块契约（每个范式都遵守，实现一次复用八次）

**每范式 → 隐含市值(亿) → 目标价 → 赔率**，契约固定：

时间序列以「量」作列、公式作行：

| 步骤 | 公式 | 引擎位置 |
|------|------|---------|
| 隐含市值(亿) | 各范式 `mcap`（见 §1–§8） | `PARADIGM[key](params, pl, ctx)` |
| 目标价 | `目标价 = 隐含市值 / 总股本` = `mcap / shares_yi` | `runValuation` 里 `target = mcap/shares` |
| 赔率 | `赔率 = 隐含市值 / 当前市值 − 1`（等价 `目标价/现价 − 1`） | `odds = mcap/current_mcap_yi − 1` |

【Fact】(model_engine.js) `runValuation` 对每条 paradigm 返回 `{key,name,weight,mcap,target,odds,diagnostic,ok,detail}`；`ok=false` 或非有限 `mcap` 不进融合。

**折现 r 约定（★2026-08-12 用户改制：统一 8–10%，旧 12–18% 档全部弃用）**（所有含终值/远期的范式统一，用小数）：

| 档位 | r | N 含义 |
|------|-----|--------|
| [COMPOUND] 稳定复利/成熟 | **0.08** | 到稳态年数 |
| [ACCEL] 常规成长（缺省） | **0.09** | 到稳态年数（引擎缺省即 0.09） |
| [EARLY] 极早期/高不确定/期权 | **0.10** | 行业定（如核聚变 N=7、人形零件 N=5），≤情景兑现期 |

**硬边界 `0.08 ≤ r ≤ 0.10`**：pe/leader/endgame/兑现期限的 `r` 一律落在此区间，不确定性溢价改走 **N（拉长年数）或档位倍数**表达，不再抬 r——r 抬到 15% 会把远年终局值折没，等于把第五档范式静默关掉。
【Fact】折现因子 = `1/(1+r)^N`。MATURE/稳态当年利润不折现（N=0，引擎默认 `n=0` 即因子=1）。

## 0.5 五档估值等级系统（★2026-08-12 用户口径固化——排序、徽章、升档赔率的唯一标准）

估值范式不是并列关系，是**随景气度/叙事强度/FOMO 逐级升档的阶梯**。页面三处必须同一套档位：**加权估值卡片与横条图按 第一档→第五档 排列**（app.js `tierOf()` 自动归档），每卡打「第N档」徽章；卡区上方渲五档等级带（`#val-tier-strip`，标出当前主锚档=权重最大范式所在档）；**开篇章 `ladder` 每档填 `tier:1-5`** 同序渲染。

| 档位 | 景气度/叙事状态 | 估值范式族 | 升档赔率 | e.g. C端类 | e.g. B端类 |
|---|---|---|---|---|---|
| **第五档** | 故事很大、叙事 FOMO，景气度催化剂有，情绪点燃 | **TAM终局法 / 五年规划法 / 对标大哥法** | 100%~300% | 20A汾酒、20A创新药 | 26E大模型 |
| **第四档** | 增速很快(40%+)空间大；缺当期业绩，经营杠杆很高 | **PS(高利润假设×PE) / 单位利润法(×PE×N+2的量) / N+2 PE** | 50%~100% | 20A电车 | 21A新能源-宁德等 |
| **第三档** | 景气度较好，较高增长(20%~40%)，拔静态估值 | **PEG / N+1 PE** | 30%~50% | 20A/25A新消费 | |
| **第二档** | 景气度一般走静态；或景气很好利润爆发但预期不可持续 | **静态 / Forward PE**（EV/EBITDA 同族） | 20%~50% | 20A疫情-消耗品 | 26E存储 |
| **第一档** | 景气度最差、当期亏损，重置成本法思维 | **PB / 合理利润率×PE(另类PS) / 单位市值法** | — | 周期底部，猪鸡有色 | |

**引擎 8 范式 → 档位映射**（app.js `tierOf()` 已实现，填数时对齐语义）：
- `pbroe` → 第一档；`implied`（合理利润率×PE 反推）→ 第一档族（诊断腿，恒殿后）；「单位市值法」（元/GW、元/W 等）引擎无专用腿→手工算后走 `sotp` 单行或 ladder 自定义档，标第一档。
- `pe`（`year_offset ≤1`，静态/Forward）→ 第二档；`evebitda` → 第二档。
- `peg` → 第三档（N+1）。
- `pe` 且 `year_offset ≥2`（N+2 PE，取期选择器切远年时**卡片自动升第四档**）→ 第四档；「单位利润法/PS 高利润假设」＝隐含净利率×远年量的算法，用 `pe` 远年腿或 `endgame` 变体承载，标第四档；`sotp` 混合锚 → 第四档区。
- `leader`、`endgame`（TAM 终局/五年规划）→ 第五档。

**使用纪律**：① 判「当前市场用的是第几档」（＝ladder `current` 那档），升档故事必须写清**从第几档升到第几档、催化是什么**——升档赔率区间（二 20–50%…五 100–300%）就是 `switches.elasticity` 的标定尺；② 档位越高前提越强，第五档范式必须搭配 09 矛盾地图的可证伪跟踪，不许单独撑加权目标的主要权重（第五档权重合计 >50% 时页面上要有解释）；③ 降档路径至少写一条（增速掉档 → 第三档 PEG 失效 → 回落第二档静态 PE，对应 `switches` 的向下条目）。

**单位铁律**（易错，[Risk]）：
- `r / adj / share / net_margin / roe / coe` = **小数**（0.09、0.60、0.25）；`r` 硬边界 0.08–0.10。引擎 `pct()` 会 ×100 显示。
- `g`（PEG 增速）= **百分数值原样**（20 表示 20%），因为 `targetPe = peg × g` 要让 PE≈增速%。
- `pe / peg / mult / pe_mid / leader_mcap / 各 _yi` = 原值（倍数、亿元）。
- `link` = 布尔，不是数字（不出现在滑块白名单，只在 page_model 里配）；`year_offset` = 数字（预测年 0-based 序号）。

## 1. leader — 对标大哥法（可比锚，映射「可比公司」权重）

> ★ **2026-07-21 用户反馈固化两条硬规则**：
> ① **大哥必须点名**——`leader_name` 必填（公司全名+代码+一句为何可比，如「村田制作所 6981.T（被动元件全球一哥·电感直接对手）」）。未点名：页面卡片打红 ⚠️「必须点名是谁」、CK-4 不过。**严禁只填一堆数字不说对标的是谁。**
> ② **默认口径 = 收入占比 → 市值占比**（`basis:'revenue'`）：本司稳态收入 / 大哥收入 = X% → X% × 大哥市值（再调整、折现）。利润占比（`basis:'profit'`）作 double-check 第二轨，**双轨背离 >30% 必须解释**（通常=净利率差，说明谁的利润率结构更优/更差）。

**公式**（引擎实现）：
```
V_potential = (follower_steady / leader_current) × leader_mcap    // 占比对标: 收入%→市值%
V_adj       = V_potential × clamp(1 + adj, 0.70, 1.30)            // 调整±30% 硬夹逼
mcap        = V_adj / (1 + r)^n                                    // 折现到今天
```

**params 字段（对齐 `PARADIGM.leader`）**：

| 字段 | 含义 | 默认取值区间 | 单位 |
|------|------|-------------|------|
| **`leader_name`** | **★必填：大哥全名+代码+为何可比** | 如「村田制作所 6981.T（…）」 | 字符串 |
| **`basis`** | **口径：'revenue'(默认)=收入占比 / 'profit'=利润占比** | revenue | 字符串 |
| `leader_current` | 大哥的对标口径数（basis 对应的收入或利润，注明报告期与汇率） | 大哥实测 | 亿 |
| `leader_mcap` | 大哥当前市值（注明日期与汇率） | 大哥实测 | 亿 |
| `follower_steady` | 本司稳态同口径（收入口径建议 link P&L 末年收入） | 自建稳态 | 亿 |
| `adj` | 调整净额（成长溢价+/小盘折价−/治理折价−） | −0.30 ~ +0.30，超界被 clamp | 小数 |
| `r` | 折现率 | **0.08–0.10**（成熟 0.08 / 成长 0.09 / 极早期 0.10；引擎缺省 0.09） | 小数 |
| `n` | 折现年数 | 0–5 | 年 |
| `metric` | 旧字段，仅 detail 文案兜底（"利润"→等效 basis:'profit'） | 建议改用 basis | — |

`adj` 组成（叠加后夹到 ±0.30）：成长溢价 +0.10~+0.20、小盘折价 −0.10~−0.20、毛利差按差距缩放、治理折价（ADR/关联交易/家族）−0.05~−0.15。

- **适用**：本司与大哥**商业模式同类**、大哥是市场化定价成熟龙头、有公允流动性。大哥数字（收入/市值）从实测来（web/iFind/年报），跨币种注明汇率，标 EST。
- **展示**：估值卡顶部渲 `leader-line`（对标大哥：<b>名字</b> · 口径 收入占比→市值占比）；引擎 detail 自带「本司X亿/大哥Y亿=Z% × 大哥市值」链路；范式 `name` 建议写成「对标大哥(村田·收入占比)」让横条图也自明。
- **禁用/[Risk]**：模式不可比（寒武纪 vs NVDA 可，vs TSMC 不可——设计 vs 制造），静默产出垃圾。堆叠溢价别想突破 ±30% 上限。

## 2. pe — PE 法（映射「历史均值」权重，默认最大锚）

**公式**：
```
prof = link ? P&L预测年净利[year_offset] : fwd_profit_yi     // 见 §0.link 规则
mcap = prof × pe / (1 + r)^n
```

**params 字段（对齐 `PARADIGM.pe` + `fwdProfit`）**：

| 字段 | 含义 | 默认取值区间 | 单位 |
|------|------|-------------|------|
| `link` | true=从 P&L 模型取 Forward 净利（活链） | 成长股建议 true | 布尔 |
| `year_offset` | 预测年 0-based 序号（0=第1预测年） | 默认最后一预测年 | — |
| `fwd_profit_yi` | 硬编码 Forward 净利（`link≠true` 时生效） | 自建 | 亿 |
| `pe` | 目标 PE 倍数 | 见下表 | 倍 |
| `r` | 折现率 | **0.08–0.10**（成熟 0.08 / 成长 0.09 / 极早期 0.10；引擎缺省 0.09） | 小数 |
| `n` | 折现年数（MATURE 用 0=不折现） | 0–3 | 年 |

**PE 分档默认（维度作行）**：

| 档位 | PE | r | Fwd 年 |
|------|-----|-----|-------|
| ACCEL 常规成长 | 20–25x | 0.09 | 2–3 |
| COMPOUND 稳定复利 | 25–30x（龙头 30–35x） | 0.08 | 2–3 |
| MATURE 消费/制造 | 12–20x | — | TTM(n=0) |
| MATURE 周期 | 10–15x | — | 中枢(n=0) |
| HEADWIND 逆风 | 6–10x 折价 | — | TTM(n=0) |
| EARLY 极早期 | 20–25x | 0.10 | N（行业定） |

- **适用**：正持续盈利的成长/成熟股。link:true 时改 P&L 假设 → 净利 → 估值全联动。
- **禁用/[Risk]**：亏损/微利用不了。**周期股必须用中枢利润，禁用峰值**（周期 PE 反向：顶部 5–8x、底部 15–20x）。市场折价/溢价是判断项，须写"%及依据"。

## 3. peg — PEG 法（映射「增速匹配」权重）

**公式**：
```
prof     = (isFinite(profit_yi) && link≠true) ? profit_yi : P&L预测年净利[year_offset]
g_used   = clamp(g, 0, g_cap)          // 引擎默认 g_cap=50
targetPe = peg × g_used                 // PEG=1 时 PE 数值=增速%
mcap     = prof × targetPe
```

**params 字段（对齐 `PARADIGM.peg`）**：

| 字段 | 含义 | 默认取值区间 | 单位 |
|------|------|-------------|------|
| `link` | true=从 P&L 取 Forward 净利 | 视情 | 布尔 |
| `year_offset` | link 时预测年序号 | 默认末年 | — |
| `profit_yi` | 硬编码净利（`link≠true` 且已设时生效） | 自建 | 亿 |
| `g` | 盈利 CAGR（**百分数值**，30 表示 30%） | 15–40 | 数值% |
| `peg` | 目标 PEG | 默认 1.0，带 0.8–1.5 | 比值 |
| `g_cap` | g 上限，防超增速吹爆 PE | 默认 50 | 数值% |

- **适用**：正、可持续、中速增长（增速匹配腿，PE-anchor 融合里占 30% 权重）。
- **禁用/[Risk]**：周期股、亏损股禁用。超高增速必须靠 `g_cap` 封顶，否则 PE 荒谬。本 skill 无专用 PEG 文件，公式为标准金融（`PE=PEG×g`）自撰。

## 4. sotp — A+B / 分部估值（容器范式：主业+副业各挑锚）

**公式**：
```
mcap = Σ_i (segments[i].profit_yi × segments[i].mult) + net_cash_yi
```

**params 字段（对齐 `PARADIGM.sotp`）**：

| 字段 | 含义 | 说明 | 单位 |
|------|------|------|------|
| `segments[]` | 分部数组 `{name, profit_yi, mult}` | 每部一行；`mult` 是页面可调滑块（`segments.i.mult`） | — |
| `segments[].profit_yi` | 该分部净利 | 由 §10 净利率传导得出 | 亿 |
| `segments[].mult` | 该分部估值锚倍数 | 各挑自己档位锚（PE/PS/终局/大哥/EV-EBITDA/PB-ROE） | 倍 |
| `net_cash_yi` | 净现金（现金−有息负债，±长股投/少数股东） | 页面可调 | 亿 |

- **适用**：多业务/控股型；每个 segment 是一次独立范式调用，SOTP 是其他范式的天然容器。**与 Part3 `segments[].model.seg_val` 逐行对齐**（分部模型章节 3.2+ 展示的就是这些行的展开），主业 base 行与期权行的映射关系写进各段 seg_val.note。
- **规则/[Risk]**：
  - **非经营资产显式行**：机房/物业/长股投/净现金等不进主业量价的资产，SOTP 里单列行（或并入 net_cash_yi 注明），与 Part3 残差段呼应——漏了=归属加总对不平。
  - 市值归属列加总（Σ segments + 净现金）= **当前总市值 ±1%**（§10 算账总表）。
  - 任一 ACCEL/EARLY 分部跑 ≥2 锚交叉验证（§9 分歧规则）。
  - **防重复计期权**：主业 PE 已高出同业 5–10x 的部分本身就是期权，不能再单独加期权行。
  - 净现金极易漏；禁止把嵌套价值层（终端+模组+材料）当整链市值加总。

## 5. pbroe — PB-ROE 法（金融/资源/强资产/破净）

**公式**：
```
pb   = roe / coe
mcap = equity_yi × pb        // = 净资产 × ROE/COE
```

**params 字段（对齐 `PARADIGM.pbroe`）**：

| 字段 | 含义 | 默认取值区间 | 单位 |
|------|------|-------------|------|
| `roe` | 稳态 ROE | 0.08–0.20 | 小数 |
| `coe` | 股权成本 | 默认 0.10（≈r） | 小数 |
| `equity_yi` | 净资产（BVPS×股本） | 实测 | 亿 |

- **适用**：银行/保险/资源/重资产负债表/破净标的（估值方法树：金融·资源·强资产 → PB/NAV）。
- **禁用/[Risk]**：轻资产成长股用 PB 失真。ROE 须用可持续中枢，非单年高点。

## 6. evebitda — EV/EBITDA 法（重资产/周期/折旧重制造）

**公式**：
```
eb   = link ? P&L预测年EBITDA[year_offset] : ebitda_yi
ev   = eb × mult
mcap = ev − net_debt_yi        // EV 减净债务回到股权价值
```

**params 字段（对齐 `PARADIGM.evebitda` + `fwdEbitda`）**：

| 字段 | 含义 | 默认取值区间 | 单位 |
|------|------|-------------|------|
| `link` | true=从 P&L 取 Forward EBITDA | 建议 true | 布尔 |
| `year_offset` | 预测年序号 | 默认末年 | — |
| `ebitda_yi` | 硬编码 EBITDA（`link≠true` 时生效） | 自建 | 亿 |
| `mult` | EV/EBITDA 倍数 | 默认 10；周期 6–10 / 稳态 8–12 | 倍 |
| `net_debt_yi` | 净债务（负数=净现金则加回股权价值） | 实测 | 亿 |

- **适用**：重资产/周期/折旧摊销重（估值树：周期性强·重资产 → EV/EBITDA 或中枢 PE）。桥接股权靠净债务。
- **禁用/[Risk]**：**周期用中枢 EBITDA，禁用峰值**。轻资产低折旧股 EV/EBITDA 无意义。

## 7. endgame — 终局份额法（大 TAM 里占独特位）

**公式**：
```
terminal = tam_yi × share × net_margin × pe
mcap     = terminal / (1 + r)^n
```

**params 字段（对齐 `PARADIGM.endgame`）**：

| 字段 | 含义 | 默认取值区间 | 单位 |
|------|------|-------------|------|
| `tam_yi` | 终局 TAM（**2 个独立来源**验证） | 自建 | 亿 |
| `share` | 终局份额（对标竞争格局，龙一 0.60–0.80 非 1.0） | 0.15–0.80 | 小数 |
| `net_margin` | 稳态净利率（对标海外大哥） | 见 §10 传导表 | 小数 |
| `pe` | 稳态 PE | 默认 22；20–25x，龙头 30x | 倍 |
| `r` | 折现率 | **0.08–0.10**（成熟 0.08 / 成长 0.09 / 极早期 0.10；引擎缺省 0.09） | 小数 |
| `n` | 到终局年数 | 3–7 | 年 |

- **适用**：确定大 TAM 里占独特位置的早期龙头（寒武纪/Palantir 型）。
- **强制敏感性/[Risk]**：TAM ±20%、份额 ±5pt、净利率 ±5pt、PE ±5x 四向压测。份额禁写 100%。

## 8. implied — 反推隐含（诊断范式，权重固定 0）

**公式**：
```
cur        = ctx.currentMcap ?? current_mcap_yi
impProfit  = cur / pe_mid            // 市场隐含净利
impRev     = impProfit / net_margin  // 市场隐含收入
mcap       = cur (diagnostic=true, 不进融合)
```

**params 字段（对齐 `PARADIGM.implied`）**：

| 字段 | 含义 | 默认取值区间 | 单位 |
|------|------|-------------|------|
| `pe_mid` | 中枢 PE（反推用） | 默认 20 | 倍 |
| `net_margin` | 合理净利率（反推收入用） | 默认 0.10 | 小数 |
| `current_mcap_yi` | 兜底当前市值（引擎优先用 ctx.currentMcap） | = valuation.current_mcap_yi | 亿 |

- **用途**：产出"市场已 price in 到哪一年 / 哪个假设撑估值"，是融合旁边的对照腿，不是目标市值发生器。
- **[Fact]** 引擎标 `diagnostic:true`，`runValuation` 融合时自动剔除（`weight` 无论设多少都不进 `V_blend`）。设 `weight:0`。

## 9. 加权融合 + 分歧区间 + 默认权重预设

**加权融合**（`runValuation` 实现，只对 非诊断 & weight>0 & 有限 & ok 的范式）：
```
V_blend = Σ_k (w_k × V_k) / Σ_k w_k        // 权重自动归一，wsum=Σw_k
目标价_blend = V_blend / shares_yi
赔率_blend   = V_blend / current_mcap_yi − 1
```
【Fact】(model_engine.js) 权重不必自己归一，引擎按 `w/wsum` 重新归一；诊断腿(implied)与 weight=0 腿不计入。
**★页面显示口径（2026-08-17 石英股份读者反馈「彼此的权重需要有影响啊，加权的权重=1」）**：估值卡印的必须是**有效权重 `wnorm`（Σ=100%）**，滑块原始值只在括号里给；拖任一根滑块，全部卡片的有效权重同步重算并刷新（app.js `wLabel()`），hero 区一句「权重已归一」。算法一直是归一的，之前只是印了原始值、读者当成彼此独立——**派生量的显示口径要与算法一致**（06 §3.0e ④）。写 page_model 时仍建议 Σweight≈1，便于人读。

**分歧区间规则**（引擎按活跃范式离散度出 verdict）：
```
dispersion = (V_max − V_min) / V_max
  <0.20   → 'ok'   多锚自洽·出点估计 V_blend
  0.20–0.50 → 'warn' 有分歧·出区间[V_min,V_max]+标主锚+差异来源
  >0.50   → 'risk'  冲突·禁出单值·查分歧变量(TAM口径/大哥不可比/净利率过乐观)
```
引擎同时返回 `range.{min,max,median,dispersion,verdict}`。展示时每范式各自 `赔率 = V_k/当前市值−1` 排序 + min–max 须状线，并把实测当前市值锚并列，预期差 >15% 须解释。

**默认权重预设**（PE-anchor 三锚，来源 implied-horizon.md 历史40/可比30/增速匹配30）：

| paradigm key | 映射 | 默认权重 | 说明 |
|-------------|------|---------|------|
| `pe` | 历史均值 | 0.40 | 主锚 |
| `leader` | 可比公司 | 0.30 | 对标大哥 |
| `peg` | 增速匹配 | 0.30 | PEG≈1 |
| `sotp` | — | 0（按需开） | 多业务/控股型时提权 |
| `evebitda` | — | 0（按需开） | 周期/重资产时提权 |
| `pbroe` | — | 0（按需开） | 金融/资源时提权 |
| `endgame` | — | 0（按需开） | 极早期大 TAM 时提权 |
| `implied` | 诊断 | 0（强制） | 永不进融合 |

[Inference] "其余小权重"= 按 archetype 把相关锚提权、无关锚归 0，再让引擎归一。archetype→提权建议：

## 9.5 · Forward 利润取期选择器 + 静态范式活链写回（★2026-07-22 华丰 688629 固化）

**取期选择器**（用户高频需求：「PE 按 2 年后还是 3 年后还是 5 年后利润算」）：
- 前提：`forecast_years` 建 **5 年**（3 年模型没有"5 年后"可取；第 4-5 年为代际/竞争稳态外推，`part3.note` 注明不确定性升档）。
- 在 `#valuation-blend` 前插按钮组（2026E…2030E）：点击 → `pe.params.year_offset=off; pe.params.n=off`（**折现年数=年距同步**，2026E=0 不折…2030E 折 4 年）+ peg/evebitda 的 `year_offset` 同步 + 三范式 `name` 改写（卡片标题随取期变）→ relink+recompute。
- 附**隐含读数**一行实时刷新：「<年>E 归母 X 亿 × PEx ÷ (1+r)^n → 现市值 ÷ 该年归母 = Yx」——把"看远一年贵多少"翻成直读数字，是选择器的认知价值；须与算量器/假设滑块联动后同步刷新。
- **纪律提示写在选择器下**：取远年利润宜同步下调 PE 档（高成长档 28-40x → 增速回落年 20-28x，在 PE 卡滑块自调）——选择器只切年份不动倍数，否则远年利润×高档 PE=双重乐观。
- **时间语义锚不跟随**：SOTP 恒锚爆发后首个可见利润年（如 2027E）、终局法恒锚终局年、leader 恒锚稳态收入年——各范式异期是语义设计不是 bug；全体跟随=变相"全体后移"拉估值。

**静态范式活链写回**（勾稽完整性，与 04 §5.5 呼应）：pe/peg/evebitda 设 `link:true` 即活链；**sotp/leader/endgame 引擎不支持 link**、params 是静态值——任何"改假设→看估值"的交互页面，必须在改动回路里写回：`sotp.segments[].profit_yi`=取锚年归母×该段毛利占比、`leader.follower_steady`=稳态年收入、`endgame.net_margin`=终局年净利率；分部估值卡（`.sm-val`）同步改 DOM。**验收=拖任一假设杆，估值区 DOM 数字必须动**（读 textContent，非引擎值）。SOTP 行名不要嵌硬编码数字（如"10.4 亿×35x"），活链后名值矛盾——写"组件(AI 互连)×35x"，数字交给 detail。

## 10. SOTP 净利率传导 + 算账总表（sotp 分部利润的来源）

**净利率 = 毛利率 × 行业传导率**（填 SOTP `segments[].profit_yi` 前先算净利率，公司级 ±2% 校验）：
```
传导率     = 公司级净利率 / 公司级毛利率
业务净利率_i = 业务毛利率_i × 传导率
校验: Σ(营收_i × 净利率_i)/Σ营收_i ≈ 公司级净利率 (±2%)
segments[i].profit_yi = 营收_i × 业务净利率_i
```

**行业传导率表（维度作行）**：

| 行业 | 传导率区间 |
|------|-----------|
| 芯片设计 | 0.40–0.55 |
| 光模块·通信 | 0.65–0.85 |
| 品牌消费 | 0.55–0.65 |
| 半导体设备 | 0.40–0.50 |
| 软件·SaaS | 0.20–0.35 |
| 创新药 | 0.15–0.30 |
| 传统制造 | 0.35–0.55 |

[Risk] 传导率错配（把低毛利老业务混进高毛利成长线）是英维克案 −67% 误估的直接原因，必做公司级 ±2% 回验。

**算账总表（固定列序，SOTP 展示用）**：
```
| 业务 | 档位 | 最新期 | 营收(亿) | 净利率(%) | 净利(亿) | 估值锚 | 锚倍数 | 市值归属(亿) | 占比(%) | 隐含假设 |
```
硬规则：市值归属列加总（+净现金行）= 当前总市值 ±1%；每分部一句隐含假设；末行给 market-implied 核心 PE = (当前市值 − Σ稳态baseline) / 核心业务利润。

## GOTCHAS（落 page_model 前逐条核）

- **link 语义**：`pe/evebitda` 设 `link:true` 才走 P&L；`peg` 则是 `link≠true 且 profit_yi 已设`→用 profit_yi，否则走 P&L。想活链就 `link:true`+`year_offset` 选预测年。
- **单位混用**：`g` 是百分数值(30)，`r/adj/share/net_margin/roe/coe` 是小数(0.09)。写反直接偏两个数量级。`r` 出 0.08–0.10 区间＝违规（不确定性走 N 或档位表达）。[Risk]
- **周期股**：pe / evebitda 一律中枢利润/中枢 EBITDA，禁峰值。
- **implied 权重**：设 0；即便误设正权重，引擎因 `diagnostic:true` 仍剔除，但别指望它进融合。
- **SOTP 净现金**：`net_cash_yi` 在 sotp params 内（不是 valuation 顶层那个），漏了归属加总对不平 ±1%。
- **leader 可比性**：模式不可比会静默出垃圾。**双轨核验是人工动作，引擎不算**——引擎单实例只按一个 basis 出数；作者须手动用另一 basis 重算一遍（换 leader_current/follower_steady 口径），背离>30% 在页面/note 解释（通常=净利率结构差）。引擎的 'risk' verdict 只来自 runValuation 跨范式离散度>50%，与双轨无关。**leader_name 未填=CK-4 不过**（引擎 detail 会打「⚠️大哥未指明」）。
- **融合前置**：`ok=false`（如 leader 缺 leader_current、pbroe 缺 equity_yi、pe 净利=0）的范式不进 `V_blend`；确保关键锚 params 齐全。
- **⚠️未查到**的输入宁可留空标注，不编造 params 值喂引擎。
