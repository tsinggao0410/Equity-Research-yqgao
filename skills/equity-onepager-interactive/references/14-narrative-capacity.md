# 14 · 1.7 可交易容量与波动位置（叙事／题材篮子）

**做什么**：给标的挂上的**叙事**（韭研公社产业链）与**题材**（问财所属概念）逐个算三个量——
容量、换手强度、我的份额——回答「钱来了摊多薄、我能不能分到」。
顺带给第二章每个阶段一条**篮子对照**，把 R/M/V 里的 M（板块/贝塔）从估值变成实测值。

产出两块：
- `part1.narrative_capacity` → **1.7 可交易容量与波动位置**（横截面）
- `part2.phases[i].basket_beta` → **2.2 阶段列内 个股 vs 篮子 涨幅对照**

> ⚡Phase 1.7（在 1.6 筹码龄之后跑）。**不需要 API key**，走本机 Chrome 拦截网站自己的 XHR。
> 首次跑要装 Playwright：`python3 -m pip install playwright && playwright install chromium`。

## 1. 第一性原理：股价＝资金 ÷ 筹码

**叙事决定钱往哪去，容量决定钱摊多薄，我的份额决定我分到多少。**
所以**单看容量没有决策含义**——一个 8,347 亿的数字不配上「钱有多少」和「我占多少」，推不出任何东西。
三个量必须凑齐：

| 量 | 指标 | 回答什么 |
|---|---|---|
| **分子** 叙事势能 | 换手强度 ＝ Σ成交额 ÷ Σ自由流通市值，及其三年分位 | 钱来了没有？ |
| **分母** 容量 | 自由流通市值加总 | 钱要摊在多大盘子上？仓位放不放得进去？ |
| **份额** 我的位次 | 篮子内自由流通排名 + 占比 | 钱来了会不会买到我？ |

**容量大 ≠ 需求大，正好相反**：容量大＝吸收力强、单位资金推力小。
储能篮子 105,957 亿自由流通，3,412 亿成交额也就换手 3%，推不动；
外贸出口篮子 880 亿，来 50 亿就是暴力行情。
**真正有赔率的形态是失配——叙事级别高但篮子小。**

实测巨星科技最锋利的一行：**储能换手强度第 76 分位（钱确实来了），但巨星排第 98/895、只占 0.2%——
钱来了也买不到我**。这一句直接解释了阶段⑤储能篮子 +8.4% 而个股 −23.1%。

**为什么不用日振幅分位**（早期版本用过，已废）：波动低有两种相反解释——没人玩（冷）、
或筹码锁死蓄势（要爆），方向不单调，做不了决策输入。换手强度是单调的：钱进来就抬、没来就低。

## 2. 叙事 ≠ 题材：先选对来源再谈容量

| | **叙事**（韭研公社产业链） | **题材**（问财所属概念） |
|---|---|---|
| 来源 | 人工梳理、事件驱动，点名给成分 | 机器打标，沾边就挂 |
| 回答 | 市场在讲什么故事 | 资金会往哪个池子里找票 |
| 巨星科技（手工具出口商）出来的是 | **中美降税、越南工厂、外贸出口** | 芯片概念、军工、储能、机器人概念 |
| 成分规模 | 单链 20–30 只 | 单概念 55–1215 只 |
| 附带信息 | 建链日期、逻辑要点、更新时间 | 无 |
| 覆盖 | 只有被研究过的题材 | 全 A 股都有标签 |
| 一次运行 | 14.2s / 4 POST | 28.9s / 18 POST |

**先看韭研，没有再退回问财。** 两者口径一致（容量三口径 + 三年分位），可以直接横比。
一只票的叙事篮子通常两三千亿，题材篮子动辄十万亿——差的那个量级就是
「故事讲给谁听」和「钱实际能进多少」的区别。

题材词模式下如果问财有同名概念，会与韭研叙事并排出并算**成分重合度**，这是两套口径之间唯一的硬桥：
重合度 94% 说明这条叙事就是题材的核心；重合度 43% 说明它讲的是别的事，只是蹭到了这个池子。

## 4. 概念选取三道闸（缺一个都会选出没法用的概念）

**闸一 · 机制标签**：融资融券、沪深股通、中报预增、参股银行——不描述主业，剔。
**闸二 · 伞形标签**（`UMBRELLA_MIN=500`）：成分股过多的标签对单个公司没有定位信息。

## 5. 口径（写进报告必须标）

容量三个，从松到紧：`total_mktcap` 名义盘子 ／ **`float_mktcap` 真正能换手的（「可交易容量」看这个）** ／
`amount` 今天实际吃得下多少钱。

- **换手强度**＝Σ成交额 ÷ Σ自由流通市值（5 日平滑），三年分位窗口 1095 自然日
- **自由流通股数**由「当前自由流通市值 ÷ 最新收盘价」反推，期内视为不变
- **两个篮子别混**：容量用全部成分股；分位用自由流通前 60 只（历史序列只对这 60 只建），输出里分开标
- **离散度**：日均横截面标准差＝`mean_t(std_i(超额收益))`，用日频不用累计（累计方差会被窗口长度污染）
- **R²**＝成分股超额对篮子超额回归的均值，衡量这条叙事解释了多少波动
- **β**＝本股对篮子的弹性
- 离散度／R²／β **三者都先减去沪深300 再算**，否则全市场普涨时每条线 R² 都很高，问不出「是真因子还是标签」

**篮子指数已剔除本股**，否则个股权重大时超额会被自己稀释（巨星占「外贸出口」自由流通市值 22.5%）。
成分与权重取当前值回溯套用，**含幸存者偏差**，图注必须写明。

## 6. 六个坑（都已在代码里处理，改代码时别踩回去）

| 坑 | 表现 | 对策 |
|---|---|---|
| **科学计数法** | 问财把成交额返回成字符串 `"3.1685751922E8"`，正则漏掉指数部分就差 1 亿倍，**而且静默**，加总看着像 0 | 解析必须吃 `E` |
| **`page` 参数是假的** | `meta.page` 恒为 1，改 page 每次返回同一批，`perpage` 硬顶 100 | 靠总市值游标翻页；**排序必须放进第一条查询**，否则首批无序会让游标落太低（实测漏成 101/200）；永远拿 `meta.extra.code_count` 校验行数 |
| **单一 K 线源会被拦** | 腾讯 gtimg 返回 `waf.tencent.com/501page.html` 而不是 JSON | 新浪 → gtimg 失败转移 + 连续 12 次失败熔断 |
| **覆盖不足别硬算** | 7 只股票算出来的分位是废数 | `basket_history()` 返回 `coverage`/`reliable`，低于 60% 输出「数据不可得」 |
| **问句 ~200 字符硬上限** | 超了返回 `-9138「question字段长度过长」`。25 个 6 位代码加指标尾巴就会超 | `chunk_codes()` 按**长度**切块不按个数；**服务端错误码一律进 `notes`，绝不能当成空结果**——否则调用方以为这批标的不存在，实际是 25 只全被吞、加总印出个 49 亿 |
| **韭研成分股要精确过滤** | `keyword` 字段把成分股和题材词混在一起，而问财多标的查询里只要掺进一个题材词，整条查询返回 0 条 | `roster.py` 拉全 A 股名册（5239 只，一次性 115s，缓存 30 天）做精确匹配，模糊规则不行；港股成分（泉峰控股、创科实业）同时排除并单独列出 |

## 7. 报告怎么写

### 7a. 1.7 节（`part1.narrative_capacity`）
标题给关键词：**「可交易容量与波动位置」**。正文三段，每段一句话回答一个量，**不要单独摆容量数字**：

1. **钱来了没有**——换手强度当前值 + 三年分位；分位高说明资金已在，低说明还没来
2. **摊多薄**——自由流通容量；同时给叙事篮子与题材篮子，量级差本身就是结论
3. **我能分到多少**——篮子内排名与占比。**这一句是全节的落点**，用 `.hl` 标出来

写法示例（照抄这个句式，不要写成「XX 分析」）：
> 储能篮子换手强度已到三年第 76 分位，钱确实来了；但这个篮子 895 只成分、10.6 万亿自由流通，
> 巨星排第 98、只占 0.2%。钱来了也买不到我。

**必须标的口径**：容量看自由流通、分位篮子是前 60 只、成分权重取当前值回溯套用含幸存者偏差。

### 7b. 2.2 阶段列（`part2.phases[i].basket_beta`）
这是这个模块真正的价值：阶段分解里的 **M（板块/贝塔）原来只能估，现在有实测锚**。
每个阶段列内加一行「个股 X% ／ 对照 Y% ／ 超额 Z%」，其中篮子已剔除本股。

**与 `factor_quant` 的关系**：`factor_quant.m_pp` 是从 TTM 净利率反推的利润率层贡献，
`basket_beta.excess` 是相对同叙事篮子的超额。两者口径不同，**不许互相替代**，但可以互证——
若某段 M 贡献很大而超额接近 0，说明那段涨的是整个篮子，不是这家公司的 alpha，
该段的 `logic` 必须写明这一点。

#### 7b-0. ★概念诞生日硬闸（2026-08-14 补，阳光电源实跑抓出来的结论级错误）

**叙事篮子有诞生日，股价历史没有。把今天的概念套到它诞生之前的阶段上，算出来的超额是伪读数。**

韭研标题里的 `(260709)` 就是建链日，`chain_date()` 早就在抽它（离散度窗口一直在用），
但阶段对照那一段原来完全没看它，11 条篮子无差别套到 6 个阶段上。阳光电源实测：

| 阶段 | 窗口 | 阶段起点时已存在的篮子 |
|---|---|---|
| ① 储能第一波 | 2022-04~08 | **0 / 11** |
| ② 长熊杀估值 | 2022-08~2024-02 | **0 / 11** |
| ③ 沙特大单 | 2024-02~09 | 1 / 11 |
| ④ 美国政策恐慌 | 2024-09~2025-05 | 4 / 11（AI 电力四条全部不存在） |
| ⑤ 主升浪 | 2025-05~11 | 5 / 11 |
| ⑥ 盈利证伪 | 2025-11~2026-08 | 6 / 11 |

800V HVDC 建链 2026-07-09、固态变压器 2026-05-18、AI电力出海 2026-03-09。而阶段④的
`logic` 里写着「同期 AI 电力四条叙事篮子等权 +16.2%、超额 −46.4pp」——那四条当时一条都不存在。

**这比幸存者偏差更硬**。幸存者偏差是「输家掉出了名单」；这里是**整个类别事后定义**：
2026-07 圈出来的「800V HVDC」成分，本来就是照着已经涨完的那批票挑的。
所以旧 `note` 里那句「含幸存者偏差」盖不住它，必须整行剔除。

**闸门（`onepager_module.py` 已在生成期强制）**：
- `born > 阶段起点` → 该行**不进 `rows`**，落到 `dropped[]` 里，带 `born` 与 `chg_if_forced`（只交代，不给结论用）
- `born` 抽不出来（标题无日期）→ 同样剔除，理由写「建链日不可核」
- `rows` 与 `bench` 双空 → `usable=false`，**该段整块不渲染，`phases[].logic` 里不得出现任何篮子数字**
- 留下来的行仍是当前成分回溯套用，幸存者偏差照旧要在图注写明——两道限制是叠加的，不是二选一

#### 7b-1. 同期对照锚：申万二级行业指数 + 沪深300（`basket_beta.bench`）

硬闸之后早期阶段会整段没有对照，所以补一条真·同期存在的腿：`bench_index.py`。

```bash
python3 bench_index.py --list 光伏          # 先查申万二级行业名，别凭印象猜
python3 onepager_module.py --name 阳光电源 --model page_model.json \
        --bench 光伏设备,电网设备,电池 --write
```

选申万二级不选东财行业板块：东财 `stock_board_industry_hist_em` 在本机被远端掐
（`RemoteDisconnected`），申万走 akshare `index_hist_sw` 稳定；更重要的是**行业分类是持续维护
的成分表，不是事后按涨幅圈出来的概念**，结构上没有定义后验问题。历史深度实测：
801733 其他电源设备Ⅱ 到 2014-02，光伏设备／电池／电网设备 到 2021-12（2021 分类改版）。
`first_date > 阶段起点` 的锚同样出 `error` 不出数。

**行业锚与概念篮子不同源，绝对值不可直接比**，只比方向与量级——一个是申万成分加权、
一个是当前成分等权回溯套用。

**⚠️ 补这条腿不是补一张图，是要回头改 `phases[].logic`。** 阳光实测两段结论被改掉：

| 阶段 | 原（污染篮子） | 新（同期锚） | 结论变化 |
|---|---|---|---|
| ④ 2024-09~2025-05 | AI电力四条 +16.2%，超额 **−46.4pp** | 光伏设备 −17.6%，超额 **−12.5pp** | 「独自被抛弃」→「行业在跌，本股多跌 12pp」 |
| ⑥ 2025-11~2026-08 | AI电力四条 +5.6%，超额 **−47.5pp** | 光伏设备 −26.7%，超额 **−15.2pp** | 「叙事有效但这只票没被选中」→「行业整体在跌，本股额外多跌 15pp」 |
| ⑤ 2025-05~2025-11 | AI电力四条 +69.6%，超额 +177.6pp | 光伏设备 +79.8%，超额 **+167.4pp** | 方向与量级都成立，这段原结论碰巧对了 |

④⑥ 两段的仓位含义完全不同：原写法指向「筹码/风格问题，故事还在」，
真实读数指向「行业 beta 在杀，公司自己再多担一截」。**污染篮子把行业跌幅整个藏起来了**。

### 7a-2. ★龙头 / 中军 / 后排 + K 线方位（2026-08-14 用户要求加，`tiering.py`）

**「谁在定义这条线的涨幅」比「这条线有多大」有用得多。** 三量回答的是「钱来了买不买得到我」，
分层回答的是「钱来了先买谁」，方位回答的是「那几只现在在什么位置」。

**分层判据（`tier_members`）——龙头是行情属性，不是规模属性：**

| 层 | 判据 | 含义 |
|---|---|---|
| **龙头** | 窗口内累计超额排前 20% **且 β≥1 且超额为正** | 这条线的涨幅由它定义 |
| **中军** | 自由流通市值前 1/3 且非龙头 | 盘子扛得住，钱进来先买它 |
| **后排** | 其余 | 弹性可能最大，但要等前两层先动 |
| **相对最强** | 全篮子超额最高的那只也是负的 | **这条线没有龙头**——叙事在讲，钱没进来 |

**★「超额为正」这一条不能省。** 整条线都在跌时，前 20% 分位照样是负数，
把一只超额 −10% 的票叫「龙头」是错的；那种情况下**「没有龙头」本身就是结论**。
阳光实测 10 条篮子里，绿色甲醇那条判成无龙头（超额最高的中国中车也只有 −7%）。

**★页面原来把「自由流通市值排名 ≤3」标成「龙头」——那是规模排名，已改掉。**
阳光在 8 条 AI 电力篮子里市值全排第 1，页面全给它标了龙头；而按窗口超额它**每一条都是中军**。
英伟达电源方案那条最刺眼：龙头麦格米特 +93%、中国西电 +88%、四方股份 +104%，阳光 −18%。
同一个故事，钱去了别人那儿——这句话是「篮子超额 −46.6pp」给不出来的。

**展示名单也跟着改**：原来取自由流通前 6，会把龙头整个漏掉（龙头常不在市值前列）。
