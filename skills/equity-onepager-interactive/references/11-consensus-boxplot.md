## 0 · 三道必过的口径闸（每条都有实测反例）

### 0.1 ★ FMP 的历史「区间」有一大截是**合成的**

FMP 对早年缺失的分析师分歧会**回填一个固定比例的假区间**：

| 标的 | 合成区间 | `lo/avg` | `hi/avg` |
|---|---|---|---|
| 002371 | FY2015–FY2022 | 0.9448 | 1.0593 |
| 300750 | FY2018–FY2022 | 0.8479 | 1.2823 |
| 0700.HK | FY2015–FY2022 | 0.8819 | 1.0427 |
| **AAPL** | **FY1998–FY2023（26 年）** | **0.80** | **1.20** ← 字面 ±20%，铁证 |

同期覆盖家数在 8~17 之间跳，**比值纹丝不动**——这不是真实分歧。

**不剔除的后果**（002371 净利润，实测）：`avg_range_pos` = **−0.46**、区间命中率 54.5%；
剔除后 `avg_range_pos` 翻转为 **+0.53**、区间命中率 **100%**。**结论完全反过来。**

脚本 `mark_synthetic_bands()` 探测式识别（连续 ≥3 期 `lo/avg`、`hi/avg` 都相同），
**per-ticker，绝不写死年份**——各家的比例值不同、终止年份也不同（AAPL 一直延续到 FY2023）。
比值必须从**未取整的原值**算：np 以「亿」计、eps 以「元」计，同样 `round(...,4)` 保留的有效位数差 4 个数量级。

命中的期：排除出**全部**兑现统计 + 页面画灰标「合成区间」。

### 0.2 ★ EPS 的历史兑现整体下线

FMP 预期 EPS 用**固定/漂移的隐含股本**，实际 EPS 用**当年报告加权股本**，**分母不同源**：

- 002371：预期隐含股本 FY2015–FY2023 恒为 718.3M，而实际加权股本 396M → 722M
- 300750：`Low/High` 的隐含股本**钉死** 4540.3M，而 `Avg` 的自己在漂（FY2023 4384M / FY2024 4962M / FY2025 5161M）

相减就会得出**数学上自相矛盾**的结论：

| 期 | 净利润 | EPS |
|---|---|---|
| 002371 FY2016 | −12.70% miss | **+48.50% beat** |
| 002371 FY2018 | −10.30% miss | **+40.61% beat** |
| 300750 FY2025 | −8.58% miss | **+3.90% beat** |

> 曾尝试「把实际 EPS 按预期口径隐含股本重算」——**对 300750 失效**（分母自己在漂），
> 且即便成功，EPS 的 beat/miss 会与净利润完全同号（分子分母都是净利润的线性变换），本就不含独立信息。

**所以：已披露期不画 EPS 实际值、不进统计**；未来期 EPS 区间保留（分母是当前股本，与市值同口径，forward PE 要用）。
**看兑现记录只看收入与净利润**——那两条腿的实际值与预期同源同口径。

### 0.3 财报前一致预期按**营收值**配对，不按日期就近

A 股年报与一季报公告只差两三周。实测 26Q1（2026-03-31）以 17 天之差抢走了 2026-04-17 那行
（实为 FY2025 年报），把 **真 miss 判成 beat +132%**，同时真正的 26Q1 行（2026-04-30）被彻底孤立。

修法：`match_earnings_row()` 用 `revenueActual` 与当期 income-statement 营收值匹配（相对误差 ≤0.5%），
并加**一对一认领**约束；配不上的期写 `gaps` 并退回用区间均值判定。
另需剔除 `earnings` 里 `date==报告期末`、估计值全空的**占位行**（002371 实测 2019~2024 每年 12-31 各一条）。

### 0.4 附带：两个统计口径的坑

- **`surp_vs_pre` 与 `surp_vs_avg` 不能混算**：两个基准不是一回事（point-in-time vs 当前快照）。
  实测 002371 季度 EPS：`basis=pre` 的 15 期均值 +24.5%、`basis=avg` 的 13 期 +11.6%，混出的 18.5% **不对应任何真实口径**。→ 分列报。
- **退化区间**（宽度 < 均值 1%）不计 `range_pos`：分母趋近 0 会把微小偏离放大成离谱数值
  （实测 AAPL 某期 lo=1.429/hi=1.4291 → `range_pos` = **1010**，`avg_range_pos` = 55.6）。
  且 `avg_range_pos` **只对落在区间内的样本求均值**，越界的单独计数。

## 1 · 这一节要解决什么

一页纸原来有个断层：

| 章节 | 回答的问题 | 时态 |
|---|---|---|
| 1.1–1.4 | 这家公司过去长成什么样 | 已发生 |
| **1.5（本节）** | **市场认为它接下来长成什么样，以及市场过去猜得准不准** | **市场预期** |
| 三、P&L 建模 | **我**认为它接下来长成什么样 | 我的判断 |
| 四、矛盾地图 | 我和市场的分歧在哪、赔率多少 | 分歧 |

没有 1.5，第三章的模型就是**悬空的**——你算出 FY2027 净利 104 亿，好还是不好？只有把它放进「卖方 93–135 亿、均值 112 亿、7 家覆盖」这个分布里才有意义。
所以 1.5 的箱线图上会画一个 **◆ = 第三章模型值**，且**随假设滑块实时移动**——拖滑块的瞬间就能看到自己从分布下沿滑到上沿。

第二件事是**兑现记录**。分歧只是静态的，还得知道这家公司**历史上是不是系统性藏利润**：

- 连续 N 期 beat → guidance 保守，卖方一致预期是地板，第三章可以往上打；
- 连续 N 期 miss → 一致预期是天花板，别拿卖方数当基准；
- **beat 却不涨 / miss 却不跌** → 当期股价交易的**根本不是这份财报**，去第二章翻那一段的主要矛盾。

最后一条是本 skill 的老命题：`fetch_earnings.py` 的文档里写着 002371「业绩连续超预期而股价 −31%」。
实测本节自动抓出 002371 **12 次预期与股价背离**（24Q2 beat 股价 −6.7%、24Q3 beat −6.4%…），正是那段行情。

## 3 · 三个口径坑（全部已在脚本里显式处理，**不要绕过**）

### 3.1 箱体是「全距」，不是四分位 —— 这是红线

FMP 每期只给 **Low / Avg / High + 覆盖家数**，**拿不到四分位数**。
所以本节画的是 **全距箱**：箱体上下沿 = 最低/最高预测，中线 = **均值**（不是中位数），须帽外标 `n=`。

页面必须渲出 `box_caliber` 这句口径声明，**删了 CK-1.5 不过**。把全距箱说成四分位箱，等于把「一个极端乐观分析师」和「四分之一的人」混为一谈——**分歧度会被系统性高估**。

> **想要真四分位箱线图**，必须有**逐家机构**预测：
> · 港股 → `fetch_fundamentals_hkus.py` 的 `consensus`（etnet 逐家机构纯利/EPS/目标价/评级，实测腾讯 19 家）——**这一格港股比 A 股好取**；
> · A 股 → AlphaPai / iFind 逐家预测；
> 拿到后在 `quarters[]/years[]` 里补 `q1/med/q3`，渲染层可升级成真箱线图。

### 3.2 A 股「年度厚、季度薄」，薄样本必须画虚线

实测覆盖家数：

| 标的 | 年度（FY26–FY29） | 季度（未来 4–8 期） |
|---|---|---|
| 300750.SZ 宁德时代 | 收入 24–29 家 / EPS 11–25 家 | 收入 **2–4 家** / EPS **1–2 家** |
| 002371.SZ 北方华创 | 收入 8–18 家 | 收入 **3–6 家** / EPS **1–3 家** |
| 0700.HK 腾讯 | 收入 21–44 家 | 收入 5–12 家 |
| NVDA | 收入 13–40 家 | 收入 11–26 家 |

结论：**A 股看年度、季度只作参考**；港美股季度可用。
`coverage` 逐指标算（`rev`/`eps` 各自一个）——实测 300750 FY2024 收入 24 家但 EPS 只有 2 家，用 `max()` 会把「EPS 样本极薄」盖掉，箱线图就会骗人。
`coverage!=='ok'`（默认 <3 家）→ 页面**虚线箱 + `⚠ n=`**，且**不得**引用进第三章假设或第四章 `D`。

### 3.3 报告币种 ≠ 交易币种

腾讯 0700.HK **报 CNY 却交易 HKD**（实测 `reportedCurrency: CNY`）。
传 `--page-currency` 后脚本回填 `currency_warn`，页面渲红条。**本节金额与页面其余 `*_yi` 不同币，不可相加、不可直接比市值。**

### 3.4 附带：远端脏数据自动标记

FMP 远端年份常因覆盖骤降出现「收入环比上行、EPS 均值反跌」。实测 NVDA FY2030 `epsAvg 12.29 < FY2029 15.32`（覆盖 16→11 家）。
脚本**不修数**，只在该期打 `suspect` → 页面标 ⚠️，**不进 forward PE**。

## 4 · 怎么读这两张图

### 4.1 箱线图

| 看什么 | 怎么读 | 下游用途 |
|---|---|---|
| **箱体高度** | `spread = 全距/均值`。>0.3 基本就是卖方在打架 | → 第四章 `part4.items[].D`（分歧度）**直接用**，`dispersion_basis` 写「n 家，极差 x–y 亿」 |
| **箱体随时间张开** | 近端窄、远端宽 = 正常；**近端就宽 = 当期财报本身有大分歧**，值得下钻 | → 找矛盾 |
| **中线斜率** | 均值的增长斜率 = 市场隐含的增速假设 | → 与第三章 `q_growth/p_growth` 对照 |
| **◆ 的位置** | 我的模型 vs 卖方分布。◆ 在箱体下沿=我比市场保守；上沿=我更乐观；**箱体外=我在下注一个市场没在算的东西**，第四章必须有一条对应矛盾 | → 第四章赔率 |
| **`n=`** | 覆盖家数。骤降的那一期通常也是数据最脏的一期 | → 数据纪律 |

**◆ 只在「未来年度」口径出现**——第三章模型是年频，季度口径不可比，季度视图下不画（这是刻意的，不是 bug）。

### 4.2 兑现记录（⚠️ v2 已改版，以下描述部分失效）

> **v2 变更**：独立的 beat/miss 柱状图**已并入 §4.1 的箱线图**（★=实际值直接画在箱体上）。
> 统计条移到图下方，并按基准分列。**EPS 的历史兑现已整体下线（见 §0.2），只看收入与净利润。**
> 以下保留旧版说明供理解判定逻辑。

- **柱** = 实际 vs 卖方一致预期的偏离（绿 beat / 红 miss / 灰 inline）。
  `inline` 判定带默认 **±2%**（`fmp_config.json` 的 `_inline_band_pct`）——**不许把 +0.3% 叫 beat**。
- **折线** = 财报后 **1 周**股价反应（需 `--kline`）；tooltip 里另给 4 周。
- **◇ 菱形点** = `divergence`，即 **beat 但跌 / miss 但涨**。

统计条给：样本期数、命中率、beat/miss/inline、平均超预期、中位超预期、当前连续 streak。

> **中位数比均值重要**。实测 002371 平均超预期 +15.5% 但中位只有 +4.4%——说明是**少数几次大幅超预期拉高了均值**，常态其实只是小幅 beat。只看均值会得出「这公司总是大幅超预期」的错误结论。

**背离必须解释，不能只画。** CK-1.5 要求：`divergence` 点名的期，回第二章对应阶段核对主要矛盾。

### 6.4 口径提醒

- `earnings` 的 `epsActual` 是**单季**；`analyst-estimates(annual)` 的 `eps` 是**全年**。**两者不可直接比。**
  实测 300750：FY2025 `epsAvg 15.30` ≈ 四个单季实际 `3.19+3.63+4.10+4.87 = 15.79`。

- 金额单位：脚本已统一换算成**亿**（原报告币种），EPS 保留每股原值。
