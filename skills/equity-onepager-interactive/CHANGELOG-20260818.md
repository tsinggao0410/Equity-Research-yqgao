## 一、1.4 改成**逐季 · 堆积面积图** · 毛利率分解（上市以来）

> 用户（二稿定版）：「毛利率分解要是季度的，并且只保留 净利率+四费+税费+其他（把其他的所有统计起来），用堆积面积图！！！」

```
毛利率 ＝ 净利率 ＋ 销售 ＋ 管理 ＋ 研发 ＋ 财务费用率 ＋ 税费 ＋ 其他
```

- **七层，不多不少。** `税费` ＝ 税金及附加＋所得税费用合成一层；`其他` 是**一个桶**，
  把剩下的全部装完（减值 / 政府补助 / 投资收益 / 公允价值变动 / 营业外 / 少数股东损益），
  按恒等式反算 → 恒等式永远严格成立（实测 26 季逐季 ±0.02pp 全对）。
- **毛利率不画成层，它是面积上沿。**
- **面积图比堆积柱对**：Chart.js 的堆积折线是**代数累加**（负值照样进 running total），
  上沿恒等于各层之和；堆积柱把正负段分到零轴两侧，视觉顶 ≠ 总和，亏损期公司还得额外画一根记号。
  这一版因此把中间那版加的 `grossTop` 插件整个删掉了——面积图不需要它。
- **逐季不是逐年**：费率的结构变化是季度级发生的，年度序列会把拐点抹成一条斜线。
- **纵轴稳健截断**：分母是单季营收，上市初期收入极小的公司会把量域拉到 ±1500%
  （寒武纪 2020Q1 营收 0.12 亿、堆积峰值 938%），近八季结构被压成贴零轴一条线。
  按最近 8 季定轴，被截的 11 个季度在图注里**逐个点名极值**，悬停仍给真值。

## 二、1.4b 与 1.4 的取数合并进 `fetch_quarterly.py`，折旧不再摊平

> 用户：「你的 CAPEX 和折旧摊销需要找到对应报表上的数据，不要你随便搞好吧。」

**这条是对的，之前那版把折旧按区间均摊了。** 去 iFind 把真实频率查清楚（688256 实测）：

| iFind 指标 | 频率 | 结论 |
|---|---|---|
| `单季度.营业总收入/营业成本/销售·管理·研发·财务费用/税金及附加/所得税费用/归母净利润` | **每季** | 直接取，**不要自己差分** |
| `单季度.经营活动产生的现金流量净额` | **每季** | 同上 |
| `单季度.购建固定资产、无形资产和其他长期资产支付的现金` | **每季** | 同上，即 CAPEX |
| `当期计提折旧与摊销` | **只有 0630 / 1231** | **A 股季报不含现金流量表补充资料**——单季折旧在报表上不存在 |

于是：**单季折旧不存在，就不造。**
- **单季视图只画三条**（OCF / 归母 / CAPEX，全部单季原生值）。折旧不画——
  半年值摆在单季轴上会被读大一倍，比"估算"更糟，因为它长得像真值。图注说明为什么。
- **TTM 视图才画折旧**，且**只在 Q2 / Q4 有点**：`TTM@Q4 = 当年年报累计`、
  `TTM@Q2 = 本年中报累计 + 上年(年报累计−中报累计)`，两个都由披露的累计数**精确**凑出；Q1/Q3 留空。
- **默认落 TTM 视图**：两个读数（含金量、扩张强度）本来就是滚动概念，单季比值全是噪声。
- `da_disclosure[]` 落原始披露段（12 段，寒武纪 2020全年 / 2021H1 / …），图注直接印出来。

**另一个取数陷阱（新写进 01 红线）**：同一张 iFind 返回表里**累计列与单季列同名并存**
（`销售费用` 与 `单季度.销售费用`）。脚本对季度字段**强制 `单季度.` 前缀**，匹配不到宁可留空——
退回累计列就是把 Q4 的全年累计当单季画上去。`--self-test` 里专门有一条断言钉死这件事。

旧脚本 `fetch_cash_capex.py`（含区间均摊那套）**已删除**，由 `fetch_quarterly.py` 取代。

## 三、3.1 表头白字改黑字 + 加单位（这次改的是默认值，不是补丁）

> 用户：「这里要我说几次，从白色字体改成黑色……我已经说过很多很多次了。」

**为什么复发四次**：全局默认是 `thead th{background:var(--accent); color:#fff}`。
3.1 的年份表头带 `.col-hist/.col-fcst` 浅底、项目列带 `.rowlbl` panel 底、分组行 `.pl-grp` 无类——
底色被覆盖、白字留着＝看不见。2026-08-17 那一轮按「覆盖底色的规则必须同时指定前景色」补了
`#tbl-pl thead th{color:var(--fg)}`：**那是补丁，只保住了当时那一张表**，下一张新表照样复发。

**这次改默认值**：`thead th` ＝ 浅底 `--elev` ＋ 深字 `--fg` ＋ accent 下框线。
浅底深字之后，覆盖底色**不可能**再产生不可读表头，新表不必记得补任何东西。
纪律反转：**深底白字才是特例，要在同一条规则里成对申报 `background` + `color:#fff`。**

**单位**：读者「看不懂是万元还是百万元」。单位写进**表头本身**（`.th-unit`）——
分组行「金额　单位 亿元　·　比率行＝%　·　量／价行的单位写在行名里」、项目列头「金额单位 亿元」、
h2 后缀 `#pl-unit`。写在 cap/图注里不算数：表能横向滚，滚两屏 cap 早出视野了。
币种走 `MONEYU()` 读 `meta.currency`（亿元/亿港元/亿美元/亿欧元）。

新闸 **CK-8 j**（可选，`check_charts.js --html <built.html>`）：j1 全局 `thead th` 不是白字；j2 3.1 表头有 `.th-unit`。

## 四、4.5 次级叙事链去图 + 可读性三条结构闸

> 用户：「4.5 次级叙事链就不需要做图了，你本身做的都不很清楚，说的内容也很 ai，即使没有用禁词，也很难去阅读和理解。」

**去图**：撤掉每条叙事下的三坐标条与子坐标系气泡图，只留明细表。
病根不是画得丑，是**这张图不承载信息**——它复用 4.1 的三根轴，而一条叙事内部只有 3–5 个点，
点太稀读不出象限结构，两根轴的含义还得再解释一遍，读者付出「学新图」的成本，拿回的东西 4.1 全给过了。
次级矛盾天然是逐条要读的清单，清单的形态是表。
CK-6g 因此翻成「**全页只有 4.1 那一张 `<svg class="cmap">`**」，4.5 里再出现就报错（防渲染层被回滚而没人发现）。

**可读性**：用户后半句才是要害——「即使没有用禁词」。**禁词表治不了这件事**。
让链读不动的是三种结构性毛病，都可机检（新增 CK-6f2/f3/f4）：

| 毛病 | 长相 | 闸 |
|---|---|---|
| 一环里没有数 | 「下游需求持续释放带动价值量提升」——四条链共用，换个标的照抄也成立 | f2 每环 `claim` 含阿拉伯数字 |
| 一环写成一段 | 60 字以上不是一环，是把推导过程原样倒出来 | f2 每环 ≤60 字 |
| 一条链十几环 | 越多越像在凑传导，真有关节的通常 4–6 个 | f3 `chain.length ≤ 6` |
| 空口标「已证实」 | 证实与否是这一节唯一的产出 | f3 `status==='已证实'` 必挂 `ev` |
| weakest 说不清哪一环 | 「最弱的是需求端」没法跟踪 | f4 必须点名第几环 |

人工三条（09 §7a-2）：每一环要有**主语**（公司/客户/对手/监管，不是「行业」「需求」这类没有行为能力的词）；
不许自造代号；上一环的宾语＝下一环的主语，接不上说明中间漏了一环或这两环本来无关。

## 五、2.2 R/M/V：底部没有利润的段不许再用 PE 做 V 层

> 用户：「如果底部没有利润或者用第一档估值的公司，在底部 R/M/V 归因的时候就不应该再用 pe 了，可以用 pb 或者其他，否则 pe 的扰动就太大了。」

**不是精度问题，是定义问题。** `R=ln(Rev₁/Rev₀)`、`M=ln(NM₁/NM₀)`、`V=ln(PE₁/PE₀)`，
盈利趋零时 `NM→0`、`PE→∞`，**`ln` 在这两处没有定义**。硬算的后果每次长一个样：
**V 吃掉整段涨幅、R 与 M 被挤成两根看不见的短条**，读者得出「这一段全是估值在动」，
而真相通常是**「这一段根本没有盈利这把尺子可用」**——两句话的仓位含义完全相反。

- `factor_quant` 新增 **`ruler`**（PE / PS / PB / EV·EBITDA）+ **`ruler_why`**，三层含义随尺子换
  （PB：R＝净资产、M＝无、V＝PB）。降级链 PE → PS（收入仍是锚）→ PB（净资产才是底）。
- 触发（起终点任一端）：归母 ≤0 ／ |净利率| <2% ／ PE >150x 或 <0 ／ 该段属**第一档估值范式**（05 §0.5）。
- `phase_valuation.py` 新增 `ruler_suggest()`，把探测结论与逐条触发理由落进 `calibers.ruler_suggest` 并在终端打警告，直接抄。
- **跨段换尺子必须让读者看见**：三根条的全部意义建立在「同尺度可跨列比」上，
  PB 段的 V 与 PE 段的 V 不是同一个量。页面三处已说破——每段**尺子徽章**（印三层新含义）、
  条带下**黄条**（「不要横着比长短」）、4.1 场景卡的历史对照条上补标尺子。
- `m_pp` 归零不许静默：要在 `basis` 里写「利润率层在本段无定义，已并入 V」，
  否则与「利润率恰好没变」在机器和读者眼里都一样。
- 新闸 CK-8 **g5**（PE 用不了却还标 PE）**g5b**（换了没写 why）**g5c**（枚举合法）。
