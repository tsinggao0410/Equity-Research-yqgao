# 统一数字底座(work/facts_spine.md)怎么建

目的:全卡同一个数前后一致;各章 agent 只从底座取公共数,底座以外的数自己回原文取并登记台账。完整样例:`examples/dekeli/facts_spine.md`。

## 建法
1. 先取一次 Wind(只取历史财务 + 细分业务,一问拿全,原始应答落盘 `sources/wind/`),或直接从年报抠表。
2. **逐项回年报原页核对**,每个数写 PDF 页码;精确值(元 / 千元)留一行「精确值(用于计算)」,表里写亿元两位小数。
3. 同一指标有多套口径时**分开列、标 ⚠**,写清各自来源表、差异原因、哪张图用哪套(如主营分产品表 vs 附注营业收入分解;按厚度 vs 按材质)。
4. 作者计算的数标〔作者计算〕并写算式;半年数与全年数分列。
5. 统稿后发现的勘误并进底座,在文件头写「统稿勘误已并入(……)」。

## 七块(按公司实际增删)
| 块 | 内容 |
|---|---|
| A 利润表与现金流(合并) | 营收、归母、扣非、毛利率、研发费用与费用率、经营现金流、capex;近 5–7 年 + 最近两个半年 |
| B 分产品 / 分部 | 收入、毛利率、占比、同比;多套口径分开;产销量表 |
| C 分地区 | 境内 / 境外收入与毛利率、占比;半年只有附注口径时写明 |
| D 客户集中度 | 前五合计、第一名金额与占比、页码;具名客户(招股书 / 问询回复) |
| E 资产负债与营运资本 | 货币资金、交易性金融资产、有息负债(是否含长期应付款与租赁负债)、应收、存货、合同负债、在建工程 |
| F 产能、产量、销量与单价 | 产能、利用率、产销量(单位写死)、平均售价(公司口径 vs 第三方报价分开) |
| G 股本、市值与治理 | 总股本、收盘价与日期、总市值(币种)、第一大股东与实控人持股、质押、解禁 |

## 表格写法
```
| 指标(亿元,%) | 2021 | 2022 | 2023 | 2024 | 2025 | 25H1 | 26H1 |
|---|---|---|---|---|---|---|---|
| 营业收入 | … |
页码:AR2023 p29(传输类 742,058,406.52 元,毛利率 26.58%)……
```
各章台账 `parts/NN_facts.md`:`| 数字 | 含义 | 来源文件 | 页码 | 原文摘录(≤40 字) |`,底座里的数也要在用到它的章台账里登记一次。
