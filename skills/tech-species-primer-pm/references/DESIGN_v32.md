- 保留:中文为主;数据纪律(数字回一手、标来源与期间、缺失写「数据不可得」);来源行小号灰字;比率折线、金额柱(两条金额序列对照用双折线);无参考系数字表改图;判断类内容逐条完整句;第四部分叫「UE与经营效率」;不写估值。

## 2 页面结构(参考报告 + v3.1 保留章节)
1. 页头:h1「{公司}({代码})业务认知」;meta 盒(日期 · 买方内部研究 · 口径说明两行:分部数据以哪份年报为准、行业数据用哪些第三方机构、底稿读了哪几份深度报告)。
2. **一、公司总览**:一段「本质是什么」(加粗核心定义)+ 一段「近况与结构性变化」→ KPI 磁贴 5 个(营收、归母、毛利率、海外占比、研发)→ 表 1 分产品经营数据(收入、占比、同比、毛利率、毛利占比、定位)→ 图 1 收入结构演变(堆积柱,5 年以上)→ 必要时图:海外/国内收入与毛利率、谁付钱(前五客户类型)。
3. **每个主要业务一章**(收入或毛利占比 ≥10%,或决定未来的新业务),章首 `p.lead`(这个业务是什么、为什么重要,一两句)+ 一行关键数(收入、增速、毛利率、量)。固定六节:
   - x.1 **行业规模**:需求公式(需求 ≈ 什么)+ 分地区/分场景历史与预测堆积柱(第三方或券商口径,写清来源页码)+「口径分歧」提示块(不同机构数字并列)。
   - x.2 **竞争格局**:份额横条(本公司高亮)+ CR/排名 + 分区域位次;口径冲突写明。
   - x.3 **历史演变**:技术/商业主线一段 + 时间轴(6–10 个节点,关键节点 hot)+ 必要时量价/毛利率历史图。
   - x.4 **具体产品**:产品谱系与代表型号参数(白话解释关键参数为什么重要)+ 研报原图或官方图 1 张(带页码)。
   - x.5 **核心竞争要点**:这门生意靠什么赢,①②③ 编号,每点一段完整话。
   - x.6 **公司优势**:用可验证证据说明本公司在上述要点上的位置(份额、认证、毛利率同业对比图、项目背书、成本、产能);也写短板。
4. **非主要业务简述**:每块一段(收入、毛利率、商业模式、为什么还保留、对主业的作用)。
5. **UE与经营效率**(v3.1 保留,同事肯定):单位经济(每个主要业务的每瓦/每瓦时收入与毛利)、定价权 2–3 条完整句、增量利润率一句,六张经营效率图(应收与存货周转天数、净利润与经营现金流、总资产周转率、资本开支与经营现金流、资产负债率与有息负债率(含长期应付款)、在手净现金),全部 ECharts,半宽两两并排(two-up)。
6. **跟什么走**(驱动):2–4 个外部变量,每个一小段 + 1 张图(例:全球装机、碳酸锂价格与储能毛利率、政策/关税时间线、汇率),敏感性写数值。
7. **正在变什么**:逐条完整句要点(加粗结论 + 证据数 + 为什么要紧 + 何时验证)6–8 条;末尾一张「核心问题与验证点」小表(指标 / 门槛 / 依据 / 时间,3 行)。
8. **来源与口径**:底稿清单(机构+日期);口径冲突与本报告取舍表;数据缺口(底稿无法解决的);声明(不含估值结论、目标价与评级;研报原图为内部研究引用,对外分发前移除)。

## 3 篇幅与密度
- 参考报告(3 个主业 + 总览 + 非主业 + 来源)约 7,700 汉字,用户仍称其为「精简版」。v3.2 大盘多业务卡目标:**全文 10,000–13,000 汉字**,其中每个主要业务章 1,800–2,600 字;中盘单业务卡 7,000–9,000;小盘 6,000–8,000。
- **图表密度(用户硬要求,2026-09-24 重申「至少要 50–60 张图」):全卡 ≥55 张图(目标 55–70),表 ≥10。**参考报告只有约 18 张图,这一点**不**照参考。其中:
  - 交互数据图(ECharts)≥30 张;
  - 官方图 / 研报原图 / 产品实物图 / 流程图与示意图 ≥20 张。**必放类别**(每个主要业务都要有,找不到就写明已查哪些文件与页码):**生产流程或工艺流程图**(制造工序、自制与外协、从电芯到 PACK 到系统集成、从订单到交付与并网)、**产品谱系与实物图**(全型号按功率段或容量排列,合成一张也算 1 张)、**原理或拓扑示意图**(为什么这样设计)、**应用场景图**(产品在客户电站、电网、数据中心里处于哪一环)、**参数对比原图**(与上代或对手对比)、**产业链与商业模式结构图**(谁付钱、从哪买、卖给谁)、**全球布局图**(研发中心、制造基地、服务网络、海外工厂)、**第三方榜单或认证截图**(可融资性、份额排名)。不收签约、剪彩、展会、合影这类照片。
  - 分章下限:一、公司总览 ≥7(KPI 不计;收入结构、毛利结构、海外与国内、产业链与商业模式结构图、全球布局图、发展时间轴、客户类型);每个主要业务章 ≥12(行业规模 2–3、竞争格局 2–3、历史演变 2、具体产品 3–4 含产品谱系与原理图、生产或交付流程 1–2、核心竞争要点 1、公司优势 2);五、非主要业务 ≥4;六、UE与经营效率 ≥9(六张经营效率图 + 单位经济 2 + 收入去向或成本结构 1);七、跟什么走 ≥5;八、正在变什么 ≥3。合计约 6+7+36+4+9+5+3 ≈ 60。
  - 官方图来源顺序:招股书(IPO2011.pdf 有工艺流程与产品图)→ 年报 → 公司官网与产品手册(`scripts/imggrab.py` 或 `scripts/visuals/fetch_visuals.py` 抓官网图)→ 研报原图(AlphaPai image 搜「阳光电源 生产流程」「储能系统 集成 流程」「逆变器 拓扑」「PowerTitan」「SST 拓扑」「全球布局」等)→ 实在没有再自绘(优先用渲染器的 flow / chain / lineup 图块,其次 `scripts/visuals/draw_*.py`,见 references/visuals_tools.md)。
  - 图多但不堆:每张图都要有一句图题说清它证明什么;同一信息不重复出图;两张相关图用 :::two-up 并排,三张小图可三列并排(:::three-up)。
- 写法:叙述为主,段落里用加粗标出核心判断(一段 1–3 处);数字紧跟来源机构或报告;每张行业图后若有机构口径分歧,加「口径分歧:」提示块;历史用时间轴;要点用 ①②③。

## 4 MD 写法约定(渲染器 render_report_v32.py 按此实现)
- 章:`## 一、公司总览`;节:`### 2.1 行业规模`(编号写在标题里)。
- 章首导语:`> [!lead] 文字`;提示块:`> [!note] 口径分歧:…`、`> [!info] …`、`> [!good] …`。
- KPI 磁贴:
  ````
  ```kpis
  2025 营业收入 | 891.8 | 亿元 | +14.55%
  归母净利润 | 134.6 | 亿元 | +21.97%
  ```
  ````
  (列:标签 | 数值 | 单位 | 副注)
- 交互图表(ECharts):
  ````
  ```chart
  {"id":"ov_rev","title":"图 1 收入结构五年演变:…","subtitle":"单位:亿元","type":"stack",
   "categories":["2021","2022"],"series":[{"name":"储能系统","data":[31.4,101.3]}],
   "unit":"亿元","height":380,"highlight":null,"forecast_from":"2026E",
   "source":"来源:公司 2021–2025 年年报…","table":true}
  ```
  ````
  `type` 取值:`stack` 堆积柱;`bar` 单序列柱(可 `highlight` 指定高亮类目下标,`colors` 覆盖);`barh` 横条(份额,本公司高亮);`group` 分组柱;`line` 折线(`labels:true` 标点值);`combo` 柱+线(`series[].type` 与 `yAxisIndex`);`pie` 环形(慎用)。`segments`/`forecast_from` 让预测年浅色。`table:true` 自动生成「表格视图」折叠表。`two_up` 由相邻两个 chart 块外包 `:::two-up … :::` 实现;三张小图用 `:::three-up … :::`。
- 时间轴:
  ````
  ```timeline
  2003 | 研制出中国首台…逆变器 |
  2019 | **全球首家出货破亿千瓦**;华为退出美国 | hot
  ```
  ````
- 研报原图 / 官方图:`![研报原图:PowerTitan 系列产品对比](images/ref_xxx.jpg "来源:东吴证券深度(2026-07-17)p30 表 12")`,渲染为 `.shot` 面板,标题在上、来源在下;官方图同样写法,标题前缀「官方图:」。
- 表:标准 MD 表,首行表头;数字列自动右对齐;合计行首格写「合计」自动加粗;表题写在表前一行 `表 n　标题`。
- 来源行:图表下方 `> 来源:…`(13px 灰);正文不放方括号页码。
- 读者标签:〔卖方估计〕〔管理层口径〕〔第三方统计〕〔作者计算〕渲染为小号灰字。

## 6 质量门槛(v3.2 demo 验收)
- 汉字总数 ≥10,000(大盘多业务);每个主要业务章六节齐全;**图 ≥55(交互图 ≥30,官方/研报原图/实物/流程/示意图 ≥20,每个主要业务都有生产或交付流程图与产品谱系图)**、表 ≥10;每张交互图有表格视图;每张图/表有来源行(机构 + 日期 + 页码或年报页码)。
- 数字:公司财务数据回年报(页码);行业数据注明机构与报告页;机构间冲突在「口径分歧」或来源与口径章并列;不写估值/目标价/评级。
- 不照抄参考报告文字(相同事实可以,句子必须重写,判断必须来自我们的材料)。
- HTML 单文件离线可开,JS 报错 0,所有图表可悬停。
