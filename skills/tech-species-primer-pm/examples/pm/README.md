# 基金经理版写法样例

两份都是可直接渲染的 MD(`python3 scripts/render_report_v32.py examples/pm/<文件> --out x.html --pm`,Palantir 那份加 `--pm-allow Palantir,PLTR`),
`scripts/test_render_pm.py` 要求它们通过 `--pm` 验收。它们只示范**通俗层**怎么写,不是完整卡片(没有 v3.2 的证据层,过不了 `--gate`)。
零章由渲染器排成研报首页式版式(导语与关键数据 + 编号分节,三线表),顺序是先比后讲:先与前代 / 同类方案对比,再讲工作原理并配产品图;全章约 1,200 字,每节 ≤160 字,以留白分隔、少用线条,关键数据是带期间的精确值;页面上不出现「白话」「打个比方:」这类标签,小标题用买方用语;正文按 buyside-voice 的 voice-rules 写。

| `pltr_plain_sample.md` | 「Palantir 没看明白公司业务」「Palantir 的产品和普通 SaaS 有什么区别」 | 零章「业务速览」:定位 + 四项关键数据(2Q26:收入、政府 : 商业、美国占比、GAAP 毛利率)/ 1 与普通 SaaS 的差异(六行对比表 + 投资含义)/ 2 工作原理 + 平台结构示意图 / 3 典型案例(空客 A350 详写;美国陆军、英国 NHS、坦帕总医院列表)/ 4 价值流向(价值流向图)/ 5 技术演变(四代平台时间轴)/ 6 跟踪指标(指标表 + 反方观点)。技术章:原理引用图 0-1;2.3 与普通 SaaS、数据平台、咨询外包的差异(分层图、三段差异、五列对比表);四代平台演变路线图;交付模式从驻场实施到 5 天训练营。业务章开头的通俗解释;22 条三列术语词典 |

用法:
- 新卡照搬**结构和写法**,类比、案例和对比对象要从本卡材料里重新找,不要照抄句子。
- 样例里的数字取自 Palantir 2026 年二季度业绩稿与 10-Q、英伟达与博通的发布稿和行业报道,只作写法示范;正式卡片一律以数字底座和原文页码为准。
- Palantir 已有 v3.2 卡片的,按 SKILL.md「已有 v3.2 卡片改成基金经理版」一节补通俗层即可。
- 两张产品图(`images/pltr_platform_sketch.svg`、`images/cpo_switch_sketch.svg`)是依据公开材料自绘的结构示意图,不含虚构的界面或数据,已在来源行注明;正式卡片按 DESIGN_pm §2 的顺序优先取官网、发布会或研报原图。
