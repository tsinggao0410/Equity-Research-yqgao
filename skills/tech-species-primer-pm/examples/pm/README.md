# 基金经理版写法样例

两份都是可直接渲染的 MD(`python3 scripts/render_report_v32.py examples/pm/<文件> --out x.html --pm`,Palantir 那份加 `--pm-allow Palantir,PLTR`),
`scripts/test_render_pm.py` 要求它们通过 `--pm` 验收。它们只示范**通俗层**怎么写,不是完整卡片(没有 v3.2 的证据层,过不了 `--gate`)。
页面上不出现「白话」「打个比方:」「举个例子:」这类标签:零章用问题式小标题分块,类比与例子只用底色区分。

| 文件 | 对应反馈 | 看点 |
|---|---|---|
| `pltr_plain_sample.md` | 「Palantir 没看明白公司业务」「Palantir 的产品和普通 SaaS 有什么区别」 | 零章:加粗一句话 / 它像什么(数字沙盘)/ 一个真实的例子(空客 A350)/ **和普通 SaaS 有什么不同**(六行对比表)/ 钱怎么来 + 钱怎么流图 / 技术怎么一步步变过来 / 最该盯的一件事。技术章:原理三层图;**2.3 和普通 SaaS、数据平台、咨询外包比,差在哪**(分层图、四段差别、五列对比表);四代平台路线图(含每代代价与三种分岔);从驻场工程师到 5 天训练营。业务章开头的通俗解释;22 条术语词典 |
| `cpo_tech_path_sample.md` | 「少了用通俗语言解释技术和技术变化路径」「CPO 和可插拔、和 NPO 的区别」 | 产业链卡的零章:**和可插拔光模块、NPO 有什么不同**(五行对比表)。技术章:原理流程图;**1.3 可插拔、LPO、NPO、CPO 到底差在哪**(四行结构对比图:光器件离芯片多远;三段差别;八行逐项对比表);可插拔 → LPO → NPO → CPO → 光进 GPU 五代路线图;技术变化对产业链价值分配的影响;17 条术语词典 |

用法:
- 新卡照搬**结构和写法**,类比、例子和对比对象要从本卡材料里重新找,不要照抄句子。
- 样例里的数字取自公开业绩稿、厂商发布与行业报道,只作写法示范;正式卡片一律以数字底座和原文页码为准。
- Palantir 已有 v3.2 卡片的,按 SKILL.md「已有 v3.2 卡片改成基金经理版」一节补通俗层即可。
