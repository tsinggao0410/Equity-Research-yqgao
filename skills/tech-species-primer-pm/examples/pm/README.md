# 基金经理版写法样例

两份都是可直接渲染的 MD(`python3 scripts/render_report_v32.py examples/pm/<文件> --out x.html --pm`,Palantir 那份加 `--pm-allow Palantir,PLTR`),
`scripts/test_render_pm.py` 要求它们通过 `--pm` 验收。它们只示范**通俗层**怎么写,不是完整卡片(没有 v3.2 的证据层,过不了 `--gate`)。
零章由渲染器排成速览版式(摘要面板 + 编号卡片),顺序是先比后讲:先与前代 / 同类方案对比,再讲工作原理并配产品图;页面上不出现「白话」「打个比方:」这类标签,小标题用买方用语;正文按 buyside-voice 的 voice-rules 写。

| 文件 | 对应反馈 | 看点 |
|---|---|---|
| `pltr_plain_sample.md` | 「Palantir 没看明白公司业务」「Palantir 的产品和普通 SaaS 有什么区别」 | 零章「业务速览」:定位 + 四项关键数据 / 01 与普通 SaaS 的差异(六行对比表 + 投资含义)/ 02 工作原理 + 平台界面示意图 / 03 客户案例(空客 A350)/ 04 价值流向(价值流向图)/ 05 技术演变(四代平台时间轴)/ 06 跟踪指标(含反方观点与把握程度)。技术章:原理三层图;2.3 与普通 SaaS、数据平台、咨询外包的差异(分层图、四段差异、五列对比表);四代平台演变路线图;交付模式从驻场实施到 5 天训练营。业务章开头的通俗解释;22 条术语词典 |
| `cpo_tech_path_sample.md` | 「少了用通俗语言解释技术和技术变化路径」「CPO 和可插拔、和 NPO 的区别」 | 零章「业务速览」:定位 + 四项关键数据 / 01 与可插拔光模块的差异(含 NPO,五行对比表)/ 02 工作原理 + 交换机俯视结构示意图(可插拔与 CPO 对比)/ 03 产业化进展(英伟达、博通)/ 04 价值流向 / 05 技术演变(五阶段时间轴)/ 06 跟踪指标。技术章:原理流程图;1.3 可插拔、LPO、NPO 与 CPO 的差异(四行结构对比图:光器件与芯片的距离;三段差异;八行逐项对比表);五代演变路线图;对产业链的影响;17 条术语词典 |

用法:
- 新卡照搬**结构和写法**,类比、案例和对比对象要从本卡材料里重新找,不要照抄句子。
- 样例里的数字取自公开业绩稿、厂商发布与行业报道,只作写法示范;正式卡片一律以数字底座和原文页码为准。
- Palantir 已有 v3.2 卡片的,按 SKILL.md「已有 v3.2 卡片改成基金经理版」一节补通俗层即可。
- 两张产品图(`images/pltr_ui_sketch.svg`、`images/cpo_switch_sketch.svg`)是依据公开材料自绘的示意图,已在来源行注明;正式卡片按 DESIGN_pm §2 的顺序优先取官网、发布会或研报原图。
