# 基金经理版写法样例

两份都是可直接渲染的 MD(`python3 scripts/render_report_v32.py examples/pm/<文件> --out x.html --pm`,Palantir 那份加 `--pm-allow Palantir,PLTR`),
`scripts/test_render_pm.py` 要求它们通过 `--pm` 验收。它们只示范**通俗层**怎么写,不是完整卡片(没有 v3.2 的证据层,过不了 `--gate`)。
零章由渲染器排成速览版式(摘要面板 + 编号卡片);页面上不出现「白话」「打个比方:」这类标签,小标题用买方用语;正文按 buyside-voice 的 voice-rules 写。

| 文件 | 对应反馈 | 看点 |
|---|---|---|
| `pltr_plain_sample.md` | 「Palantir 没看明白公司业务」「Palantir 的产品和普通 SaaS 有什么区别」 | 零章「业务速览」:定位 + 四项关键数据 / 01 业务本质(数字化业务沙盘)/ 02 客户案例(空客 A350)/ 03 与普通 SaaS 的差异(六行对比表 + 投资含义)/ 04 价值流向(价值流向图)/ 05 技术演变(四代平台时间轴)/ 06 跟踪指标(含反方观点与把握程度)。技术章:原理三层图;2.3 与普通 SaaS、数据平台、咨询外包的差异(分层图、四段差异、五列对比表);四代平台演变路线图;交付模式从驻场实施到 5 天训练营。业务章开头的通俗解释;22 条术语词典 |
| `cpo_tech_path_sample.md` | 「少了用通俗语言解释技术和技术变化路径」「CPO 和可插拔、和 NPO 的区别」 | 零章「业务速览」:定位 + 四项关键数据 / 技术本质 / 产品案例(英伟达 CPO 交换机)/ 与可插拔、NPO 的差异(五行对比表)/ 价值流向 / 技术演变(五阶段时间轴)/ 跟踪指标。技术章:原理流程图;1.3 可插拔、LPO、NPO 与 CPO 的差异(四行结构对比图:光器件与芯片的距离;三段差异;八行逐项对比表);五代演变路线图;对产业链的影响;17 条术语词典 |

用法:
- 新卡照搬**结构和写法**,类比、案例和对比对象要从本卡材料里重新找,不要照抄句子。
- 样例里的数字取自公开业绩稿、厂商发布与行业报道,只作写法示范;正式卡片一律以数字底座和原文页码为准。
- Palantir 已有 v3.2 卡片的,按 SKILL.md「已有 v3.2 卡片改成基金经理版」一节补通俗层即可。
