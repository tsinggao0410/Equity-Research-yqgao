# 基金经理版写法样例

两份都是可直接渲染的 MD(`python3 scripts/render_report_v32.py examples/pm/<文件> --out x.html --pm`,Palantir 那份加 `--pm-allow Palantir,PLTR`),
`scripts/test_render_pm.py` 要求它们通过 `--pm` 验收。它们只示范**白话层**怎么写,不是完整卡片(没有 v3.2 的证据层,过不了 `--gate`)。

| 文件 | 对应反馈 | 看点 |
|---|---|---|
| `pltr_plain_sample.md` | 「Palantir 没看明白公司业务」 | 零章六块:一句话 / 数字沙盘的比方 / 空客 A350 的前后对比 / 钱怎么来 / 四代平台 / 要盯的一件事;「是什么、不是什么」表;钱怎么流图;技术白话章五节与四代平台路线图(含每代代价与下一步三种分岔);交付方式从驻场工程师到 5 天训练营;业务章章首白话块;19 条术语词典 |
| `cpo_tech_path_sample.md` | 「少了用通俗语言解释技术和技术变化路径」 | 产业链卡的零章;原理流程图(信号从芯片到光纤走哪几步);可插拔 → LPO → NPO → CPO → 光进 GPU 五代路线图,每代写省了什么、付出了什么、谁受益谁受损;四种方案的白话对比表;技术变化对产业链价值分配的影响;16 条术语词典 |

用法:
- 新卡照搬**结构和写法**,类比和例子要从本卡材料里重新找,不要照抄句子。
- 样例里的数字取自公开业绩稿与厂商发布,只作写法示范;正式卡片一律以数字底座和原文页码为准。
- Palantir 已有 v3.2 卡片的,按 SKILL.md「已有 v3.2 卡片改成基金经理版」一节补白话层即可。
