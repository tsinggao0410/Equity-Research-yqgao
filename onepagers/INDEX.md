## 重复覆盖 · Repeat coverage

同一标的的多次覆盖，前后对读即是**核心矛盾的演化轨迹** —— 矛盾有没有被证伪、赔率往哪一侧移、估值锚有没有换尺子。
Reading successive files on one name side by side traces **how the core contradiction evolved** — whether it was falsified, which way the odds moved, whether the valuation ruler changed.
